# ReviseWise 🧠✨

An AI-powered learning platform designed to help students study smarter. ReviseWise acts as a personal AI tutor where students can discuss difficult concepts, solve doubts, take surprise practice tests, generate custom quizzes, and revise topics through interactive learning.

## ✨ Key Features
* **Personal AI Tutor:** Engage in interactive conversations to break down complex subjects into easy-to-understand explanations.
* **Instant Doubt Solving:** Get step-by-step guidance on tricky problems to build real understanding rather than just getting final answers.
* **Custom Quiz Generator:** Instantly generate tailored quizzes on any topic to test your comprehension.
* **Surprise Practice Tests:** Challenge your memory with unexpected pop quizzes designed to reinforce active recall.
* **Interactive Topic Revision:** Review key concepts efficiently with structured, engaging study sessions.

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (v18 or higher)
* npm or bun

### Local Installation
1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/revisewise.git](https://github.com/your-username/revisewise.git)
   cd revisewise
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment variables:**
   Create a `.env` file in the root directory and add your API and backend keys:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_anon_key
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   Visit `http://localhost:8080` (or the port shown in your terminal) to view the app locally.
